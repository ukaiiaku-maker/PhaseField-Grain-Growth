# Next audit run: baseline reconciliation and climb backpressure

This run is intentionally narrower than the weekend development campaign. Do not add new physics while it is running. Its purpose is to resolve two interpretation gates in the current results and to quantify how often the event model is driven into the attempt-limited zero-barrier state.

## 1. Baseline reconciliation

The exact 165-condition mechanism composite gives B0/B1 exponents near 1.63, while the independent 20-realization extended baseline gives an exponent near 1.92 with confidence intervals containing 2. The first campaign reruns B0 and B1 using the exact 192x192 production protocol, the same 200-grain post-equilibration start, the same termination at 60 grains, and seeds 5101--5120.

Configuration:

```text
configs/production/baseline_reconciliation_20.yaml
```

This is 40 runs total. Primary questions:

1. Does B0 recover a parabolic ensemble law under the exact mechanism-campaign protocol?
2. Is the five-seed B0/B1 value near 1.63 a seed/statistical effect or a protocol/provenance difference?
3. Do the mechanistic Class-B/Class-C comparators add information beyond the free power-law exponent?

Do not interpret a scan-bound exponent as an identified power law. Inspect the fixed-n=2 comparator, residual autocorrelation, radius-definition sensitivity, and the analytical comparator fits alongside the free exponent.

## 2. Climb/free-volume backpressure sweep

The existing C1--C5 calculations show very weak velocity-curvature correlation and unusually large reverse-curvature fractions. The next campaign tests whether those signatures are robust consequences of free-volume accommodation or depend strongly on the surrogate free-volume storage stiffness.

Configuration:

```text
configs/production/climb_backpressure_sweep_200.yaml
```

The transport-limited C4 architecture is held fixed while

```text
free_volume_stiffness = 0, 0.0125, 0.025, 0.05, 0.10, 0.20
```

is varied. Five matched seeds are used at 900 K, giving 30 runs total.

The zero-stiffness case is an essential control: point-defect quota/transport kinetics remain active, but the stored free-volume chemical-potential feedback is removed. Compare across the sweep:

- growth coefficient and effective exponent;
- Class-B/Class-C analytical comparator residuals;
- reverse-curvature fraction;
- velocity-curvature correlation;
- stationary fraction;
- CV/Fano/burstiness;
- event rate and effective barrier statistics.

A sharp onset of reverse motion as the free-volume feedback increases would identify the surrogate storage pressure as the source. Persistence of decorrelation/intermittency at zero stiffness would show that the event/transport architecture itself contributes independently.

## 3. Attempt-limited barrier audit

`scripts/audit_barrierless_fraction.py` streams checkpointed CSV/gzip/Parquet ledgers without loading the full ledger in memory. It reports the fraction of genuine barrier rows satisfying

```text
effective_DeltaG <= 1e-12 eV
```

plus mean and approximate 10/50/90% effective-barrier quantiles and median barrier/kBT.

The climb sweep is audited automatically. To audit the existing mechanism composite or another local campaign, set `MECHANISM_CAMPAIGN` before running the driver. The recommended target regimes are E1, SC3, SC4, J1, and J2 because their high event rates or weak temperature sensitivity make the attempt-limited fraction especially important to interpretation.

Example:

```bash
export MECHANISM_CAMPAIGN=results/campaigns/20260817T042553Z-composite-28a9a5a185
```

If the composite points to source-run directories that are unavailable on the local machine, point the audit at the underlying campaign that contains the event ledgers instead.

## 4. One-command execution

From the repository root:

```bash
git pull origin main
python -m pip install -e '.[analysis,test]'
PROCESSES=10 bash scripts/run_next_audit_20260817.sh
```

To skip the 103-test fast suite only when it has already been run on the exact checked-out commit:

```bash
SKIP_TESTS=1 PROCESSES=10 bash scripts/run_next_audit_20260817.sh
```

To include the old mechanism barrier audit:

```bash
MECHANISM_CAMPAIGN=results/campaigns/<mechanism-campaign> \
PROCESSES=10 bash scripts/run_next_audit_20260817.sh
```

The driver records the dynamic campaign paths in:

```text
results/validation/next_baseline_campaign_path.txt
results/validation/next_climb_campaign_path.txt
```

and writes summaries under `results/production_summaries/` and plots under `results/plots/`.

## 5. Interpretation gate after completion

Do not broaden the model immediately after these runs. First decide:

1. whether the baseline discrepancy is resolved;
2. whether climb-induced reverse motion survives the zero/weak-backpressure controls;
3. whether E1/SC3/SC4/J1/J2 spend a substantial fraction of event activity at zero effective barrier;
4. whether the mechanistic trajectory fits are more stable than a free single-exponent description.

Those answers determine whether the next calculation should be a causal mechanism-ablation campaign, a reparameterization of the free-volume storage closure, or a longer scaling campaign.
