# Migration-closure correction and C5 geometry audit

## Motivation

The long-horizon campaign showed that G2, T2, S2 and C5 could coarsen faster than the no-barrier B0 reference. The legacy implementation contains two normal-migration channels: the ordinary phase-field capillary kinetics and a second event-generated normal-displacement ledger. A successful disconnection event therefore both restores compatibility and can inject an additional signed PF driving pressure. This is a potential double counting of the same disconnection-mediated migration physics.

The C5 movie also showed strongly wavy boundaries. In the legacy implementation a blocked GB segment sets the mobility to zero only on the one-pixel label boundary. A diffuse interface of width four grid spacings can therefore remain partially mobile around a jagged immobilized centerline. This is a numerical/closure artifact candidate independent of the event double counting.

## Tested closures

### Legacy hybrid + line gate

This reproduces the prior model. The phase field obeys ordinary curvature-driven migration, while a successful event also adds its packet step height to the hidden normal-displacement ledger. Blocked segments arrest only the label-boundary pixels.

### Gate only + line gate

A successful compatibility/climb event changes admissibility and may relax shear, free-volume, and TJ Burgers state, but it does not add a second normal PF displacement. Migration following release is driven by the instantaneous capillary/stored-mechanical phase-field forces. The original one-pixel blocked-boundary gate is retained so the effect of removing double counting can be isolated.

### Gate only + diffuse gate

The gate-only migration closure is retained. A blocked GB domain additionally suppresses mobility with a raised-cosine profile spanning one half of the configured diffuse-interface width on either side of the centerline. This tests whether the wavy C5 geometry is caused by line-pixel immobilization of a finite-width interface.

## Important bookkeeping

Gate-only events still record their microscopic step height, Burgers vector, point-defect quota, shear-strain increment, and volumetric-strain increment in the event ledger. The correction removes only the extra normal phase-field displacement channel. It does not erase event kinematics or compatibility relaxation.

## Initial test matrix

Matched B0, G2, T2, S2 and C5 calculations use the same 192 x 192 production geometry and the same equilibrated initial state. G2/T2/S2/C5 are each compared as legacy hybrid-line, gate-line, and gate-diffuse. A separate matched C5/B0 video set is saved for direct morphology comparison.

## Acceptance criteria

The gate-only closure is favored if it removes the systematic acceleration of nominally resistive mechanisms relative to B0 while preserving stochastic waiting/release and grain-scale intermittency. The diffuse gate is favored if it reduces excess isoperimetric roughness of C5 grains relative to the legacy line gate without introducing nonphysical global arrest.

The quantitative morphology diagnostic is the per-grain isoperimetric ratio

q = P^2 / (4 pi A).

Because a pixel-lattice perimeter estimator is biased above unity, absolute q is not interpreted geometrically. Matched B0 is the reference, and the relevant quantity is the excess q of each closure relative to B0.

## Next model level

The gate-only model is a reduced compatibility-limited continuum closure. It is not the final event-only disconnection model. If gate-only behaves correctly, the next separate development target is an event-only continuum limit in which normal interface migration is generated by explicit low-barrier disconnection flux, and the classical mobility law is recovered as the high-event-rate limit rather than being added in parallel.
